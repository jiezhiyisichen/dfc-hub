节枝特效工具 · 百科

一套给地图作者与短片作者用的 Minecraft 视觉特效工具包。特效全在客户端渲染， 指令在服务端注册，所以客户端与服务端都要装。

  • Minecraft 1.12.2
  • Forge 14.23.5.2864
  • Java 8
  • 客户端 + 服务端
  • 模组 ID jiezhimod

这是什么

把做地图 / 拍短片时常用的「演出效果」打包成一条指令能调用的东西：抖屏、白屏、字幕、倒计时、 通知、聊天栏动效，外加线圈道具、喷气背包、密码盘与一整套 DFC 监控显示器。

镜头与文字

/shake 视角抖动、/white 白屏震撼弹、/sub 字幕、/notice 右下角通知。

倒计时

6 种样式，十分之一秒精度、进度条，可被红石比较器检测「还剩几秒 / 已结束」。

DFC 显示器

4×3 吊装大屏，四种页面：核心页、部件页、自定义页、曲线页，配 DFC 遥控器绑定数据源。

物品与方块

三种线圈、喷气背包、遥控器、调试棒，以及密码盘与密码控制台。

软依赖，不会崩。DFC 显示器用纯反射读 HBM 核科技（NTM-CE）的数据； 没装 HBM 时屏幕显示 NO LINK，特效类指令照常可用。

安装

  1. 装 Forge

    安装 Minecraft 1.12.2 与 Forge 14.23.5.2864，启动一次游戏生成 .minecraft/mods。

  2. 放入 jar

    把 jiezhi-1.12.2-dfcmaptools-x.x.jar 放进 .minecraft/mods/，不用解压。 服务端也要放同一个版本。

  3. 确认加载

    启动后日志里出现 jiezhi 大字 LOGO 与 JiezhiMod v3.9 is loading. 即加载成功。

  4. 自检

    进世界输入 /shake 40，画面抖动即一切正常。

为什么两端都要装：只装服务端能注册指令但看不到特效；只装客户端连指令都没有。单人游戏的集成服务器会一并注册，所以单人装了就能用。

jar 内置完整性校验，改动过（反编译、二次打包、解压改动）会报 integrity check failed，请重新下载官方发布页的完整包。

指令手册

所有特效指令权限等级 2（OP 或命令方块）。省略 [@target] 时： 玩家自己执行只作用于自己；控制台 / 命令方块执行则作用于所有在线玩家。

指令别名用途
/shake [@target] <ticks> [intensity]/cshake视角抖动
/white [@target] <ticks> [alpha]/whitescreen白屏震撼弹
/sub [@target] [ticks] <text...>/subtitle底部字幕
/subtitleclear [@target]/subclear清空字幕队列
/countdown_add <样式1-6> <名称> <秒数> [r] [g] [b]—新增 / 覆盖倒计时
/countdown_remove <名称>/countdown_re删除倒计时
/countdown_stop <名称>—暂停
/countdown_continue <名称>—继续
/countdown_test <名称> <min> <max>—剩余秒数区间检测（红石比较器）
/notice <标题> <正文...>—右下角通知卡片

视角抖动 /shake

参数范围默认说明
ticks1 ~ 2000必填持续时长，20 ticks = 1 秒
intensity0 ~ 904.0峰值摆幅（度），超过 15 已经很晕

3 tick 起振冲到峰值 → 主震指数衰减 → 余震缓慢收尾；结束后视角精确回到原位，不留偏移。

/shake 40              # 抖 2 秒，默认强度 4 度
/shake 30 12           # 抖 1.5 秒，强度 12 度（近距离爆炸）
/shake @a 60 8         # 全场抖 3 秒

白屏震撼弹 /white

参数范围默认说明
ticks1 ~ 2000必填主闪时长
alpha0.0 ~ 1.01.0峰值不透明度

整屏纯白矩形，无暗角光晕；强闪阶段叠加模糊，主闪结束后自动追加 1~4.5 秒余像（余像阶段关闭模糊）。 shader 加载失败或被占用时静默降级为纯白屏，不会崩。

/white 30              # 主闪 1.5 秒，满不透明
/white 25 0.8          # 1.25 秒，80% 强度
/white @a[team=red] 40 # 只对红队闪

字幕 /sub

默认时长 80 ticks（4 秒）；只有首参数是纯数字时才当时长，否则整段都是文本。 支持 \n 换行、\u00a7 颜色码、双引号分组；多条字幕向上堆叠。

/sub @a 80 反应堆临界，请立即撤离
/sub @a 60 "第一行\n第二行"
/sub @a 100 \u00a7c警告 \u00a7r冷却液泄漏

通知 /notice

右下角圆角黑框，标题在上正文在下，停留 8 秒后滑出；同屏最多 6 条，历史保留 300 条。 按 P 打开全屏历史（滚轮滑动、Esc 退出），任何界面打开时都不会触发。

目标选择器与颜色码

支持 @p @a @r @e @s， 常用参数：c=3（最多 3 个）、team=red（队伍）、r=30（半径）、 x= y= z=（中心点）。

1.12.2 打不出分节号，写 \u00a7 即可：\u00a7c 红、\u00a7a 绿、 \u00a7e 黄、\u00a79 蓝、\u00a7l 粗体、\u00a7r 重置。

倒计时 6 种样式

样式 4 / 5 / 6 是高精度（mm:ss.t），小数位会随剩余时间变色；1 / 2 / 3 是整秒样式。

样式外观颜色规则临期表现
1时间 + 下方横线用你给的 rgb≤ 5 秒整行脉冲放大
2\\\时间///固定红色，忽略 rgb斜杠从外向内逐个亮
3┌时间┐ 方框用你给的 rgb≤ 5 秒整行脉冲放大
4mm:ss.t≤ 10 秒小数位转黄，≤ 3 秒转红小数位颜色即提醒
5!mm:ss.t!≤ 3 秒整体转红≤ 5 秒感叹号脉冲
6时间 + 进度条条由 rgb 渐变到黄再转红条随剩余时间收缩，≤ 3 秒呼吸
 
/countdown_add 1 ready 10                 # 朴素白字 + 横线
/countdown_add 2 alarm 30                 # 红色斜杠
/countdown_add 3 locked 60 255 200 60     # 橙黄方框
/countdown_add 4 precise 45 120 200 255   # 高精度，天蓝
/countdown_add 5 tense 20 255 120 180     # 感叹号，粉紫
/countdown_add 6 bomb 30 255 90 60        # 进度条，橙红（做爆炸倒计时最合适）
  • 时间向上取整：3 秒立刻显示 03，最后 1 tick 仍显示 00:01。
  • 归零不自动删除，保留压暗的 00:00，这样 /countdown_test 名称 0 0 才能给红石「已结束」信号。
  • 样式 6 的进度条分母是添加时设定的总秒数，暂停时条会停住而不是回缩。

DFC 显示器

一块 4 宽 × 3 高 = 12 格的吊装多方块大屏，面朝斜下方，下倾角由放置时的视线俯仰决定。 放下任意一格会自动铺满 4×3（空间不够则整体取消并返还物品），右键开关机。

方块注册名页面
DFC 监控显示器jiezhimod:dfc_screen核心页 · 反应堆实时数据
DFC 部件监视器jiezhimod:dfc_monitor部件页 · 同类部件合并统计
DFC 自定义显示屏jiezhimod:dfc_custom自定义页 · 最多 8 条自选数据
DFC 曲线显示器jiezhimod:dfc_graph曲线页 · 温度 / 发电量折线

四块屏共用同一套 11 个占位方块，只是控制器不同，所以可以并排装、互不干扰。

核心页

温度 / 熔点、稳定度、能量总线（SPK）、崩溃圆盘、运行时长、事件日志。

  • 崩溃圆盘：外圈 36 格刻度的填充 = 堆芯坍缩度，顶部读数是稳定度，底部是崩溃百分比。
  • 崩溃告警：坍缩度一离开 0 整屏转红、盘心变黄、顶栏闪烁并套红边；未连接时一律不报警。
  • 离线判定：反应堆未到 100°C 时整屏画「离线」页，不会把 0 当正常读数。

部件页

同类部件合并显示，不逐台罗列：发射器（台数 / 工作中 / 功率档位 / 合计 SPK）、接收器、燃料罐（A/B 两罐液位，<15% 变黄）、 燃料喷射器、能量存储、能量爆发（核心每秒吐出的 SPK）。

自定义页 + DFC 遥控器

  1. 拿 DFC 遥控器，蹲下右键一台设备 → 记录（储罐 / 电池 / 飞轮 / 涡轮部件）。

  2. 右键自定义显示屏 → 打开面板（开机按钮也在面板里）。

  3. 把遥控器放进面板左上的槽位 → 显示「N/8 台」。

  4. 点「添加」→ 记录到的设备全部接进来（满了或重复会跳过并报数）。

关面板时遥控器自动还给你；蹲下右键空气 = 清空遥控器记录。点不到设备也没关系： 遥控器会解多方块代理链，并就近扫描 3 格取最近的可读设备。

曲线页

  • 并排两张折线图：左温度、右发电量，带面积填充与网格，右上角是当前实时值。
  • 纵轴自动量程（100 → 150 → … → 1500），量程被抬高时刻度值转暖黄色。
  • 历史窗口约 60 秒：每 0.5 秒采一点，环形缓冲 120 点，采样完全在客户端，不增加网络流量。
  • 发电量 = 所有接收器上一 tick 收到的能量之和（J/t）；没有接收器时退回核心吐出量（SPK）。
  • 只有未绑定数据源时才记断点，不会画「突然掉到 0」的假悬崖。

绑定数据源

拿 DFC 遥控器右键 DFC 核心或 DFC 稳定器记录坐标，再右键显示器完成绑定。 未绑定时所有读数显示 --，不会把 0 当读数。

全局显示规则

规则说明
刷新率 0.05 秒恰好 1 tick，数据与画面同一节拍，不插值不滞后
数值保留 2 位小数温度 / 能量 / 液量 / 百分比 / 变化率；时间保持整数秒
未到 100°C = 离线整屏改画「离线」页
0 度 + 0 稳定度不显示危急冷堆的 0% 是「没开机」
重新加载存档会重启屏幕重走 节枝OS → 自检 → 主界面
坍缩度离开 0整屏改画「错误 301 · 与核心失去连接」，停留 4 秒后自动重启

三种线圈

物品注册名效果（手持生效）
加速线圈jiezhimod:speed_coil移动速度 ×5
重力线圈jiezhimod:gravity_coil跳跃高度约 6 格

喷气背包

装在胸甲槽，把喷气开关拿在手上，按住右键起飞、松开立刻失去动力。 准星下方有热量条（绿→黄→橙），满了会过热，必须冷却到 30% 以下才能再飞。 满燃料单次最多连续飞 18 秒；跳跃键爬升、WASD 推进。

调试棒

  • 蹲下右键密码盘：改便签文字（最多 8 字符，留空显示当前密码）与固定密码（必须 6 位数字）。
  • 蹲下右键显示器：调刷新率（曲线页推荐 200 ms）。

密码盘与密码控制台

密码盘占一格、高半格，右键键面直接按键（不开界面）。默认密码是 6 位随机数，写在旁边的便签上， 每次进游戏会自动换一批。密码控制台用于输入与校验。

常见问题

装好了但指令用不了 / 特效没反应？

特效指令权限等级是 2，需要 OP 或命令方块；同时确认客户端与服务端都装了同一个版本。

DFC 显示器显示 NO LINK 或一堆 --？

这台屏还没绑定数据源。拿 DFC 遥控器右键核心或稳定器记录坐标，再右键显示器绑定。 没装 HBM 核科技时不会崩，只会显示 NO LINK。

整屏是「离线」页？

反应堆温度没到 100°C 就按离线处理。等核心升温到 100°C 以上就会切回主界面。

遥控器蹲下右键设备没反应？

会明确告诉你原因（附近没有可读设备 / 这个方块读不出数据）。对着大桶或 9×9 叶片点不准时， 遥控器会自动解代理链并就近扫描 3 格。

倒计时归零后 00:00 一直挂着？

这是刻意的，方便 /countdown_test 名称 0 0 检测「已结束」。用 /countdown_remove 名称 清掉即可。

启动崩溃，报 integrity check failed？

jar 内置完整性校验，说明文件被改动过。请从官方发布页重新下载完整 jar；自己构建的请确认三步构建全部重跑。

白屏时画面没模糊？

余像阶段（主闪结束后）故意关闭模糊；若内置 shader 被其他模组占用或资源缺失，会静默降级为纯白屏。

站点上的版本号会不会过期？

不会。GitHub Actions 每小时拉一次上游 Release，页面数据本身也不走缓存。若刚发版想立刻看到， 下载中心里有一个「手动刷新数据」按钮，点一下就会重新拉取最新的版本清单。
