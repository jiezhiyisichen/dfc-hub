RBMK 监视器

把 HBM 核科技的 RBMK 沸水堆数据搬到一块 4×3 的吊装大屏上：柱温、中子通量、氙毒化、 控制棒抽出率、熔毁风险。数据靠反射读，没装 HBM 也不会崩。

  • Minecraft 1.12.2
  • Forge 14.23.5.x
  • 不需要 JiezhiMod 本体
  • HBM NTM-CE 可选
  • 模组 ID jiezhirbmkmod
  • Gitee · baldih

这是什么

社区作者 baldih 基于节枝特效工具改出来的独立模组。屏幕的多方块结构、吊装变换、开机动画都沿用了原作， 数据层换成了读 RBMK 的实际状态。

它有自己的模组 ID，不需要装本体；和本体一起装也不会冲突，只是屏幕和遥控器会各有一套。

前置与安装

项说明
JiezhiMod不需要
HBM NTM-CE可选。装了才有反应堆数据；没装屏幕写「数据源未绑定」，模组照常启动
Java8
  1. 装好 Forge 1.12.2，启动一次生成 mods/。
  2. 把 RBMK-Monitor-x.x.jar 丢进 mods/。
  3. 进游戏用 /give 拿方块，或者去创造模式物品栏找「RBMK显示屏」。

四块屏

同一台硬件（4 宽 × 3 高，12 格），右键开关机，页面在物品形式上区分：

方块注册名显示内容
监控显示器rbmk_screen总览：平均柱温 / 最高柱温与熔毁阈值、温升速率、中子通量、蒸汽量、燃料富集度、氙毒化、控制棒抽出率、熔毁风险盘、事件日志
堆芯监视器rbmk_monitor15×15 热图，一格一根柱子，按离熔毁阈值的距离上色，过热格描边
自定义显示屏rbmk_custom最多挂 8 条外部设备读数（储罐、电池等）
曲线显示器rbmk_graph三张折线，热工组（平均柱温 / 中子通量 / 锅炉水量）与燃料组（蒸汽 / 富集度 / 氙毒化）轮换，窗口约 60 秒

曲线中断线代表数据中断，不是读数归零 —— 不会出现凭空掉到 0 又跳回来的假象。

怎么用

绑定反应堆

  1. 手上的 遥控器（rbmk_remote）右键一下控制台，或任意 RBMK 部件（会自动找 24 格内的控制台）。
  2. 再右键屏幕，绑定完成，屏幕开始自检。

挂外部设备

  1. 蹲下右键储罐 / 电池，记录这个设备。
  2. 蹲下右键自定义屏，把读数挂上去。
  3. 蹲下右键空气，清空遥控器。

告警与红石

每台屏单独一套阈值：预警温度、严重温度、温升速率、中子通量。越线整屏红闪（严重档带频闪）， 同时拉汽笛 —— 预警两声短笛，严重是持续啸叫并隔几秒重叫，走 AMBIENT 声道，基地另一头也听得见。

红石输出

九种触发条件：告警中 / 最高柱温 / 平均柱温 / 中子通量 / 温升速率 / 熔毁 / 信号丢失 / 自定义屏第 1 槽 / 关闭， 都带阈值和反相。条件成立时 4×3 的 12 格任意一格都能取到信号。

关机或没绑数据源时一律不输出，免得拆机时误触发自动停堆。

警报器（v7.2 起）

rbmk_siren 是独立方块，不依赖多方块结构，任意一面来红石信号就响。 内置 5 种音色（双音 / 急促三音 / 气笛长鸣 / 预警两声 / 熔毁长鸣），右键调音量、音调、停顿与模式， 16 种染色点一下换色，拉响时自发光。合成：2 铁锭 + 1 红石 + 3 红石灯。

配置

所有可调项在 config/jiezhirbmkmod.cfg：绑定半径、采样间隔、冷堆阈值、音量、重叫间隔、默认阈值、红石强度。

旧存档的屏幕读不到新键会走默认值（预警 500°C、严重 800°C、汽笛关、红石关），升级后行为跟以前一样。

常见问题

屏幕一直写「冷堆」

平均柱温不到 100°C 就是冷堆，正常状态，不是坏了。堆启动后会自动进入实时界面。

绑好了但显示「离线」/「数据源未绑定」

离线是绑好了但扫不到柱子 —— 确认绑定的是这台反应堆的控制台，且距离在配置的半径内。 「数据源未绑定」是根本没读到 HBM，检查 NTM-CE 有没有装、版本对不对。

要不要装节枝特效工具本体？

不要。这个模组自带改好的显示系统，装本体只会多出一套屏幕和遥控器。
