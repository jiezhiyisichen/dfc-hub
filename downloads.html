Installation

三分钟装好开档

工具与地图互不依赖，但一起装才有完整效果。以下路径以官方启动器为例。

装 Forge 1.12.2

安装 Forge 14.23.5.2864（1.12.2 的任意 14.23.x 均可），启动一次游戏生成 .minecraft/mods 目录。

放入工具 jar

把下载到的 jiezhi-1.12.2-dfcmaptools-x.x.jar 直接丢进 .minecraft/mods/。不需要解压。

解压地图整合包

把整合包内的存档目录解压到 .minecraft/saves/，启动器里选择该存档进入即可。 首次进入请允许命令方块运行。

校准 DFC 显示器

放下 DFC 显示器搭成 4×3 多方块，手持 DFC 遥控器右键核心绑定，屏幕会自动完成开机自检。

没装 HBM？

屏幕会显示 NO LINK 而不是崩溃。特效类指令（抖屏 / 白屏 / 倒计时）不受影响，可单独使用。

联机注意

工具在服务端注册指令、客户端负责渲染，两侧都要装同一个版本，否则指令可用但看不到特效。

关于下载链接失效：本站所有下载按钮都直接指向 GitHub Release 的 browser_download_url，不做二次转存。若某个版本被作者删除，按钮会退回该版本的发布页。 遇到下载慢可尝试 GitHub 加速工具，或直接在 Release 页手动下载同名文件。
