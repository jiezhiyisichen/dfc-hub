Project Overview

把一场可控的核事故，做成可以排练的演出

这张地图面向 HBM 核科技诅咒版的 DFC（暗核聚变堆）机制：堆芯升温、稳定器投运、坍缩度攀升、爆炸倒计时， 每一阶段都有对应的屏幕读数、音效与镜头语言。工具负责表现，地图负责流程。

事件流程全自动化

开机自检 → 升温报警 → 稳定器失效 → 坍缩告警 → 错误 301 → 熔毁爆炸，全流程由地图事件驱动， 可重复播放、可中途接管，不需要玩家手动补红石。

Automation · Map Logic

4×3 实时监控大屏

核心页 / 部件页 / 自定义页三块屏幕共用同一套吊装多方块。崩溃圆盘、稳定度、事件日志、温度与熔点进度条， 全部按真实堆芯数据刷新。

Live Telemetry · Multiblock

一条指令的演出效果

/shake 抖屏、/white 白屏震撼弹、 /countdown_add 高精度倒计时、/notice 圆角公告卡片， 客户端渲染，不改存档结构。

Commands · Client Side FX

纯反射 · 软依赖

对 HBM 核科技只做反射读取：装了就读数据，没装就显示 NO LINK， 不会因为缺失前置而崩档。服务端与客户端同装即可联机使用。

Reflection · No Hard Dependency

地图与工具独立下载

地图是完整整合包 .zip，工具是单独 .jar。 想只更新工具？只下 jar。想全量开新档？下整合包。互不干扰。
