HBMZZ

面向 HBM 核科技社区版（NTM:CE）与其 Leafia 诅咒版附属的附属模组。 放下一台 DFC 监控屏，它的正面就是一台工业控制台：开机自检、滚动 POST 日志，然后进入实时遥测。

  • Minecraft 1.12.2
  • Forge 1.12.2
  • 不需要 JiezhiMod 本体
  • NTM:CE 可选
  • 模组 ID hbmzz
  • GPL-3.0

这是什么

除了一块真在绘制的 DFC 监控屏，还带了机器控制面板、诅咒版控制台移植、制式枪械， 以及 Roblox 风格的线圈与喷气背包。屏幕的渲染结构借鉴了节枝特效工具（已获作者授权）， 屏上那套叫 AHBSSMFI-OS 的界面是本项目自己写的。

它有自己的模组 ID，不需要装本体，和本体一起加载也不冲突。

监控屏

屏幕正面不是贴图，是一台真在绘制的显示器：内容用 AWT 离屏画布画到一张位图上， 再作为单个纹理贴到一个 quad。画布按 256×192 逻辑像素排版，实际纹理 768×576（3 倍超采样）。

  • 任意墙屏尺寸不变形：面板可跨 1–4 格宽、1–3 格高，内容始终 4:3 等比居中，多出来的地方是黑边。
  • 整面墙只渲染一次：只有控制器格有方块实体，其余是无实体的占位块。
  • 吊装：贴着天花板下表面放置即吊装，面板绕顶边下倾，倾角 0/15/30/45/60 五档。
  • 被打掉：挂钩留在天花板，电缆吊着整块屏掉下来摆动，切成 NO SIGNAL，30 秒后断电。
  • 离线与故障：温度不到 100°C 整屏显示「离线」；坍缩时切 ERROR 301，4 秒后自动重启。
  • 链路指示灯：LINK OK / LINK SLOW / 数据中断，按最新样本的年龄变色。

四个视图

视图内容
01 核心双环量表：外环是「当前温度 / 熔点」并带指针刻度，内环是稳定度；右侧七路结构灯柱（STA / ABS / PLS / EMT / INJ / EXC / CMT），往下是储能 / 输出 / 增益、崩溃风险条与熔毁预测
02 部件MIMIC 结构图：七路通道摆成环接到堆芯，装了的通道连线是琥珀色；下方 A/B 两列燃料条
03 曲线温度填色曲线 + 发电量细线，各用各的量程；顶部时间刻度，图底标 -60s / now，下方六项统计
04 自定义自己搭的面板，显示什么、怎么排、什么时候报警都由「面板工坊」定义

开机动画只在三个时机播放：屏刚放下、存档刚加载、堆芯开始坍缩（这时播的是 ERROR 301）。其余时间一直停在实时主界面。

面板工坊

终端左列的「面板工坊」打开独立编辑窗口，改的是这块屏的一份副本，只有点「保存并应用」才写回世界。

  • 画布 31×19 格（1 格 = 8 个逻辑像素），标题带与页脚不参与布局。
  • 控件 7 种：数值表、条形仪表、环形仪表、状态灯、文本标签等；最多 24 个。
  • 规则最多 8 条，每条 4 个条件 + 4 个动作。
  • 预设最多存 32 个，可以复制粘贴。

网格是编辑器和方块共用的坐标：窗口里排好的位置，在 1×1 和 4×3 的屏上都按同一比例缩放，不重排也不拉伸。

终端操作

  • 缩放：拖右下角、滚轮、双击标题栏最大化、点「复位」。上限就是游戏窗口。
  • 左列：电源与四个视图（2×2 排布），下面是面板工坊入口。
  • 底边：墙屏宽 / 高 / 复位固定在这里，窗口再小也点得到。
  • 右侧：这块屏的实时预览，跑的是同一套画布。
  • 服务端权威：页面、电源、尺寸都发消息由服务端改再广播，两人同时开终端不会各改各的。

功率计绑定

用「监控数据线」右键一个 NTM 功率计（红色电缆仪表 red_cable_gauge），再右键监控屏， 就能读到每 tick / 每秒输出。

融毁倒计时

坍缩阶段直接用 DFC 的 explosionIn（精确到秒）；稳定阶段按两颗催化剂 damage 的实测增长速率 （滑动平均）推算到 100 的时间。损伤不再增长时不显示预测，而不是拿写死的速率假装在算。

控制台与武器

机器控制面板是本项目自己设计的扁平版：6 个槽位、一句话规则。 机器控制台则把 NTM 诅咒版的 com.hbm.inventory.control_panel 整套搬了过来 —— 控件、事件、变量、节点图、连线器都在，界面文字改成了中文。

另外还有制式枪械、Roblox 风格的线圈（加速 / 重力 / 治愈）与喷气背包套装。

常见问题

屏上一直写「离线」

堆芯温度不到 100°C 就是离线，正常。堆启动后会自己切到实时界面。

看不到数据 / 侧栏写了原因

模组用反射读 NTM，不编译依赖。装不上或者版本对不上时会降级成「读不到数据」并把原因写在侧栏，不会崩。

要装节枝特效工具吗？

不用。两者 modid 不同，各自管各自的方块；一起装也没问题。
